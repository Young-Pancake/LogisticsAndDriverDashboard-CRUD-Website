# LogisticsAndDriverDashboard

LogisticsAndDriverDashboard is a CRUD website that handles operations such as:
1. logistics team assigning a driver
2. logistics team assigning a driver and persons to drive
3. logistics team assigning a driver and delivering materials
4. logistics team assigning a driver with both persons and materials

## Technologies used
* NodeJS
* ExpressJS
* MySQL
* Embedded JaveScript

## To get started

```bash
mkdir LogisticsAndDriverDashboard
cd LogisticsAndDriverDashboard
git clone https://github.com/Young-Pancake/LogisticsAndDriverDashboard-CRUD-Website
npm init
npm install express mysql body-parser ejs
```
### MySQL setup
I used the following parameters:
1. host: 127.0.0.1
2. user: root
3. database name: logisticsAndDriverDashboard
4. port: 33061   
it's up to you to change it as you see fit
